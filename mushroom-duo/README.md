# 🍄 Mushroom Duo

Оригинальный кооперативный 2D-платформер для двух игроков. Клиент — HTML/CSS/JavaScript Canvas, сервер комнат — Node.js + WebSocket.

## Запуск клиента
Откройте `index.html` локально или опубликуйте папку `mushroom-duo` через GitHub Pages.

## Игровой сервер
Разверните `mushroom-duo/server` как Node Web Service (Node 20+). Подходит Render Free по конфигурации `render.yaml`. После публикации скопируйте HTTPS-адрес сервиса, замените https:// на wss:// и вставьте в поле «Адрес сервера» в игре.

## Управление
- ПК: ← / →, пробел или ↑ — прыжок.
- Телефон: экранные кнопки.
- Создайте комнату и передайте другу шестизначный код.

## Примечание
Бесплатные серверы могут засыпать при простое; первое подключение после сна может занять время.
