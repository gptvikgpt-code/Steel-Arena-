# 🍄 Mushroom Duo

Новая версия игры, написанная с нуля. Старый исходник не используется.

## Структура
- `index.html`, `style.css`, `game.js` — браузерная игра.
- `server/server.js` — WebSocket-сервер комнат для двух игроков.
- `render.yaml` — конфигурация развёртывания сервера на Render Free.
- `.github/workflows/mushroom-duo-pages.yml` — автоматическая публикация клиента через GitHub Pages.

## Опубликовать клиент на GitHub Pages
1. Откройте Settings → Pages в репозитории.
2. В разделе Build and deployment выберите **GitHub Actions**.
3. Workflow Mushroom Duo Pages соберёт сайт из папки `mushroom-duo`.
4. Адрес клиента будет вида `https://gptvikgpt-code.github.io/Steel-Arena-/` (после успешного первого деплоя).

## Запустить онлайн-сервер
GitHub Pages обслуживает статические файлы и не может держать постоянно работающий WebSocket-сервер. Поэтому для игры по интернету сервер комнат нужно отдельно запустить как Node Web Service:
1. В Render создайте Web Service из этого GitHub-репозитория.
2. Root Directory: `mushroom-duo/server`.
3. Build Command: `npm install`; Start Command: `npm start`.
4. После публикации возьмите HTTPS-адрес сервиса и в игре используйте его вариант с `wss://` вместо `https://`.

Render Free может засыпать при простое. При первом подключении после паузы возможна задержка.

## Управление
- ПК: ← / →, пробел или ↑ — прыжок.
- Телефон: экранные кнопки.
- Создайте комнату и передайте другу шестизначный код.

## Статус
Клиент и серверные исходники находятся в ветке `mushroom-duo`. Публикация и сетевое соединение считаются готовыми только после успешного запуска workflow и проверки двух устройств.
